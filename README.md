# Project_of_DailyExpendature — CHRONOS / SPEND ⏱️💳

A futuristic, high-performance daily expenditure and budget management application built with **React, TypeScript, Vite, and Tailwind CSS / Lucide Icons**.

## 🚀 Key Features

- **⚡ Fast Telemetry Logger & Expense Tracking**: Quick-record daily transactions with categories, payment methods, tags, and timestamps.
- **📊 Real-time Analytics & Visuals**: Category breakdowns, spend trajectory charts, burn rate monitoring, and budget limit notifications.
- **🎯 Dynamic Budget Management**: Set spending targets per category, track progress with visual gauges, and receive auto alerts when approaching thresholds.
- **💻 Interactive CLI Terminal Interface**: Command-line simulation modal for power users to execute fast commands (`add`, `list`, `stats`, `export`, `filter`).
- **💾 Local Persistence & Multi-Currency Support**: Instant offline-ready storage with currency converters (USD, EUR, GBP, PKR, INR, JPY, etc.).
- **✨ Cyberpunk / Obsidian Glass UI**: Modern dark theme with glassmorphism, fluid animations, and responsive layouts across desktop and mobile.

---

## 🛠️ Tech Stack

- **Framework**: React 18 / 19 + TypeScript
- **Bundler**: Vite
- **Icons**: Lucide React
- **Styling**: Modern CSS3 & Tailwind CSS
- **Linting & Quality**: Oxlint / ESLint

## 📦 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Faizanullah942/Project_of_DailyExpendature.git

# Navigate into the project folder
cd Project_of_DailyExpendature

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
